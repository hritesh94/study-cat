## Sounds

Every sound in Study Cat is CC0 (public domain): free to use, change and
share, no attribution needed.

| File | What | Source | License |
| --- | --- | --- | --- |
| `public/sounds/meow-1.wav` | meow | made for Study Cat by `tools/make-meows.mjs` (additive synthesis, no recordings) | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |
| `public/sounds/meow-2.wav` | longer meow | made for Study Cat by `tools/make-meows.mjs` | CC0 1.0 |
| `public/sounds/mrrp.wav` | trilled "mrrp" | made for Study Cat by `tools/make-meows.mjs` | CC0 1.0 |
| `public/sounds/mew.wav` | tiny "mew" | made for Study Cat by `tools/make-meows.mjs` | CC0 1.0 |

The cat's talking voice ("cat babble") is generated live in the browser with
the Web Audio API (`src/audio/catVoice.js`); it uses no sound files.

If you add a sound from somewhere else, it must be CC0. Add a row here with
the original page URL and the author.
